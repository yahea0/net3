# NetPulse D-Link (3G Autonomous Reconnect Guard)

تطبيق مخصص لهواتف أندرويد لمراقبة اتصال الإنترنت لشريحة رامي ليفي (3G) عبر راوتر **D-Link Anweb**، وإعادة الاتصال تلقائياً أو إعادة تشغيل الراوتر فور تجمد الشبكة **بدون استخدام Termux نهائياً**.

---

### كيفية الحصول على التطبيق وتثبيته على هاتفك مباشرة:

1. أنشئ مستودعاً جديداً على **GitHub**.
2. ارفع هذه الملفات بنفس مساراتها عبر المتصفح في هاتفك أو تطبيق GitHub.
3. بمجرد رفع الملفات، ستلاحظ في تبويب **Actions** أن GitHub بدأ تلقائياً في بناء ملف الـ APK.
4. انتظر دقيقة واحدة، ثم افتح العملية المكتملة في تبويب **Actions**.
5. ستجد في الأسفل ملفاً جاهزاً للتحميل باسم **`NetPulse-DLink-Installer`**.
6. حمّل الملف وفك الضغط عنه (ستجد بداخله `app-debug.apk`)، ثم اضغط عليه وثبّته مباشرة على هاتفك!
